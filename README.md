# Project 4 — SQL Sales Analysis

## Goal
Practice business-oriented SQL queries on a sample sales table. The CSV can also be imported into Power BI or Tableau for a dashboard.

## Included
- `sales.csv` — generated practice dataset.
- `queries.sql` — aggregation, grouping, CTE, and window-function examples.

## Try it
1. Import `sales.csv` into SQLite, PostgreSQL, MySQL, or your SQL editor.
2. Name the table `sales`.
3. Run each query in `queries.sql`.
4. Import the CSV into Power BI/Tableau and build KPI cards for total revenue, order count, revenue by product, revenue by region, and monthly trend.

**Dataset note:** This is generated sample data, not real company data. Add screenshots and your own findings to make the project portfolio-ready.
